# ANAMNESIS: The Third Witness

A 1990s-style investigative adventure game for desktop web browsers, built in Godot 4 and authored around the ANAMNESIS / Conceptual Time Model fiction.

## Player promise

You investigate an impossible event before it happens.

You are **pre-E Her #3**, the first pre-E version of Her to know from the start. A message has reached you from a version of yourself who should not exist anymore. The player must establish what is true before E arrives, using observation, testimony, records, contradictions, inference, and limited character skills.

The game is not an inventory-key puzzle chain. Physical objects exist, but progress is primarily driven by **evidence, deductions, conversations, and decisions**.

## Format

- Godot 4.x.
- Desktop Firefox first.
- Web export.
- 4:3 presentation inspired by late-VGA adventure games.
- Mouse-first point-and-click navigation.
- Keyboard shortcuts for notebook, evidence, save/load, and dialogue.
- Light RPG skills that change what the player notices, can prove, or can get a witness to reveal.
- Chapter structure. Chapter One includes the reusable engine plus the first complete playable story chapter.

## Production model

The repository is the handoff. The user only needs to say **continue** / **next slice**.

Read in this order:

1. `PROJECT_NORTH_STAR.md`
2. `CANON_ADAPTATION.md`
3. `GAME_DESIGN.md`
4. `ARCHITECTURE.md`
5. `ROADMAP.md`
6. `CURRENT.md`

The newest user instruction plus the current repository state are authoritative.
